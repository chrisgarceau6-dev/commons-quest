# scripts/

Everything the app shows is generated by code in this folder. Nothing is hand-drawn in an image editor.

| Script | Makes | Notes |
|---|---|---|
| `scrape_menu.py` | `data/menu.json`, `data/hours.json` | Pulls 14 days of menus (nutrition, allergens, diet flags) and today's hours from UMass Dining's public feeds. Runs nightly in GitHub Actions. Refuses to overwrite good data if the feed is down or returns too few items. |
| `art/pixart2.py` | — | Tiny pixel-art engine: shapes with volume shading from one light source, hue-shifted color ramps, selective outlines, and detail pixels that hide when another part is drawn over them. |
| `art/hero_presets.py` + `art/build_presets.py` | `hero_*.png` | 11 player characters (27 animation frames each) from one rig: skin and hair are palette swaps, hairstyles are geometry. |
| `art/bear3_p2.py`, `wyrm_p2.py`, `frank.py`, `hog.py`, `wall2.py` | boss sheets | 17 frames each: 6 idle, 3 hurt, 8 knock-out. |
| `art/hat7.py`, `art/nametag.py` | — | Shared chef hat and the stitched, auto-centered name tags. |
| `art/backdrops.py` | `bg_*.png` | One fight backdrop per dining hall. |
| `map/build_map.py` | `map_{day,night,snow_day,snow_night}.png` | Rebuilds the campus as a 3/4-view pixel town from the official UMass campus map PDF's vector shapes (buildings, roads, pond, fields). Put `campus.pdf` (from umass.edu) next to the script; it is not checked in. |

Python 3.11+, `pip install pillow pymupdf`.
